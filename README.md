### 👋 소개

- 브랜드 사이트, 랜딩페이지, 게임 홍보 사이트, 작은 웹앱과 웹게임을 만듭니다.
- 모든 작업은 **모바일 반응형**을 기본으로 하고, GitHub Pages로 배포합니다.
- 작업 범위는 **프론트엔드(화면)** 입니다. 회원·결제·DB 같은 서버 기능은 하지 않습니다.
- 작업물 전체는 → **[jxding-dev.github.io](https://jxding-dev.github.io/)** 한 곳에 모아 두었습니다.
